Inverted borders. One CSS property.

A card with an inverted corner, where the border and the shadow follow the curve. clip-path can cut the corner, but it cuts off the border and shadow too. border-shape reshapes the box itself. Hover the card (or tab to its button) and the notch grows.

Your browser doesn’t support border-shape yet (Chrome/Edge 147+), so you’re seeing the fallback: a normal rounded card.

.wrap { --r: 24px; --n: 96px; }

.card {
  border-radius: var(--r);  /* fallback */
}

@supports (border-shape: inset(0)) {
  .card {
    border: 4px solid #22d3ee;
    box-shadow: 0 26px 50px #000c;
    border-shape: shape(
      from var(--r) 0,
      hline to calc(100% - var(--r)),
      arc to 100% var(--r) of var(--r) cw,
      vline to calc(100% - var(--n) - var(--r)),
      arc to calc(100% - var(--r))
        calc(100% - var(--n)) of var(--r) cw,
      hline to calc(100% - var(--n) + var(--r)),
      arc to calc(100% - var(--n))
        calc(100% - var(--n) + var(--r))
        of var(--r) ccw,   /* the inverted corner */
      vline to calc(100% - var(--r)),
      arc to calc(100% - var(--n) - var(--r))
        100% of var(--r) cw,
      hline to var(--r),
      arc to 0 calc(100% - var(--r)) of var(--r) cw,
      vline to var(--r),
      arc to var(--r) 0 of var(--r) cw,
      close
    );
  }
}

/* smooth hover: register --n as a length */
@property --n {
  syntax: '<length>';
  inherits: true;
  initial-value: 96px;
}
.wrap { transition: --n .4s ease; }
.wrap:hover { --n: 140px; }

border-shape: Chrome/Edge 147+ (not in Firefox or Safari yet, proposed for Interop 2027). shape(): Chrome 135+, Safari 18.4+, Firefox 148+ (Baseline 2026). border-shape ignores border-radius, corner-shape and border-style, so the corners are drawn into the shape and the border is always solid. The tabs switch with :has(:checked) on radio buttons, so there is no JavaScript at all.
