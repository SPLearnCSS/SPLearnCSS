The CSS

@property --x { syntax: "<percentage>"; inherits: true; initial-value: 50%; }
@property --y { syntax: "<percentage>"; inherits: true; initial-value: 50%; }
@property --angle { syntax: "<angle>"; inherits: false; initial-value: 0deg; }

/* 1. spotlight: a soft light that sits at --x / --y */
.card {
  background: radial-gradient(400px circle at var(--x) var(--y),
    rgb(122 162 255 / .25), transparent 60%), #1a1f38;
}
/* 2. glow border: two masks, "exclude" keeps only the padding ring */
.ring {
  padding: 3px;
  background: radial-gradient(300px circle at var(--x) var(--y),
    #c8d6ff, #ff3d9a 35%, transparent 65%);
  mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  mask-composite: exclude;
}
/* 3. spinning edge: animate a registered angle */
.pro .ring {
  background: conic-gradient(from var(--angle), transparent 60%, #7aa2ff 75%, #ff3d9a 90%, transparent);
  animation: spin 3s linear infinite;
}
@keyframes spin { to { --angle: 360deg; } }

/* --x / --y come from the hovered zone (see styles.css),
   or from 4 lines of JS if you want real pointer tracking. */
Made by @SPLearnCSS · mask-composite is Baseline 2023 and @property Baseline 2024, so this works in every modern browser. With reduced motion the light jumps instead of gliding and the edge stops spinning.
