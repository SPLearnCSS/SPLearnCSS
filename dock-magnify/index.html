This dock? Pure CSS.

The Mac-style dock magnify, with :hover for the icon you touch and :has(+ :hover) for the icon before it, the part that used to need JavaScript. Hover the icons, or press Tab to move through them with the keyboard.

Neighbours:

The CSS

.icon { width: 64px; aspect-ratio: 1; transition: width .2s; }

/* the icon you touch */
.icon:hover { width: calc(64px * 1.6); }

/* its direct neighbours: before (:has) and after (+) */
.icon:has(+ .icon:hover),
.icon:hover + .icon { width: calc(64px * 1.3); }

/* the next ones out */
.icon:has(+ .icon + .icon:hover),
.icon:hover + .icon + .icon { width: calc(64px * 1.1); }

/* label + click bounce */
.icon::after { content: attr(aria-label); }
.icon:active { animation: bounce .5s; }
Made by @SPLearnCSS · :has() is Baseline 2023 (Chrome 105, Safari 15.4, Firefox 121). Without it, only the hovered icon and the ones after it grow. Animating width pushes the neighbours aside, like the real dock. With reduced motion the icons change size without the animation.
