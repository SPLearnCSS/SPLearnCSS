CSS can generate random() values now

Six live demos from the video. Reload the page and every card, angle and star rolls a new value.

Works in Safari 26.2+ and Chrome 156+ (Edge follows Chrome). Firefox: behind a flag.

Your browser doesn't support random() yet, so you're seeing the fallback values. Open this page in Safari 26.2+ or Chrome 156+ to see the real thing.

Scattered sticky notes

One rule, twelve notes, twelve different angles. Every element rolls its own value.

.note {
  rotate: -2deg; /* fallback */
  rotate: random(-12deg, 12deg);
  translate: random(-8px, 8px)
             random(-8px, 8px);
}

Snap to a step

A third value is the step. Each needle can only land on 0°, 15°, 30° and so on, up to 90°.

.needle {
  rotate: 45deg; /* fallback */
  rotate: random(0deg, 90deg, 15deg);
}

Stars that never blink in sync

Random position, random speed, and a random negative delay, so every star starts partway through its cycle.

.star {
  left: random(3%, 96%);
  top: random(5%, 92%);
  animation: twinkle 2s infinite;
  animation-duration: random(1.5s, 3s);
  animation-delay: random(-3s, 0s);
}

A natural entrance

Give every tile a random delay instead of an nth-child stagger. The grid arrives instead of marching in.

.tile {
  animation: rise .5s both;
  animation-delay: random(0s, .6s);
}

The gotcha: circles that turn into ovals

A custom property stores the random() function, not its result, so every var(--size) rolls again. Add element-scoped to share one roll per element.

without element-scoped
with element-scoped 
/* ovals: width and height roll separately */
.dot { --size: random(18px, 64px); }

/* circles: one roll per element */
.dot {
  --size: random(element-scoped,
            18px, 64px);
  width: var(--size);
  height: var(--size);
}

Safe to ship

Write a plain value first. Browsers without random() drop the second line and keep the first.

.card {
  rotate: -2deg;                  /* everyone */
  rotate: random(-12deg, 12deg);  /* browsers with random() */
}

/* or wrap a bigger change in @supports */
@supports (rotate: random(0deg, 1deg)) {
  .card { rotate: random(-12deg, 12deg); }
}
